# Tensormesh security advisories

This repository exists for two things, and holds **no source code**:

1. **Receiving vulnerability reports privately** — see the Security tab, or [SECURITY.md](SECURITY.md)
2. **Publishing security advisories** for Tensormesh products

It is public so that both are reachable from outside the company. Our product repositories
are not public, which is why neither could live there.

Handling process: SOP-07 — Product Vulnerability Handling (internal).
